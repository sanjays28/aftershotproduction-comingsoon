# UI/UX Pro Max Skill Configuration
# Deep Design Intelligence Engine for Claude Code & Cursor

## Core Spatial Rules
- Enforce strict layout spacing scales: 4px, 8px, 16px, 24px, 32px, 48px, 64px.
- Use explicit component structures like Bento Box Grids or Dimensional Layering where applicable.
- Reject generic, hyper-saturated "AI purple/pink" gradient designs for serious utility apps.

## Typography & Contrast Hierarchy
- Pair geometric headings with clean, readable body fonts (e.g., Space Grotesk + Inter).
- Ensure a minimum color contrast ratio matching WCAG AAA accessibility standards.
- Maintain consistent interactive indicator styles across all page layouts.

## Component Execution Frameworks
- Optimize layout structures natively using Tailwind CSS, React components, or Flexbox/Grid.
- Implement explicit micro-interactions, distinct focus rings, and clean hover state transformations.
- Always bundle a verification checklist ensuring loading states, empty states, and layout breakpoints are fully covered.
